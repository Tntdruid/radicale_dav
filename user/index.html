Calendar & Contacts (CalDAV/CardDAV)

Your calendar and address book use the same login as your email account (mailbox address + mail password) -- there's nothing to set up here. Enter your mailbox address below to get your URLs:

Server address
Calendar URL
Address book URL
Username

Most apps only need the server address plus your username/ password -- they'll discover the calendar and address book automatically (via /.well-known/caldav and /.well-known/carddav). First connection creates them if they don't exist yet.
